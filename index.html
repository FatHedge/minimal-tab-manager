Privacy Policy

Last updated: May 30, 2026

Overview

Minimal Tab Manager is a browser extension that helps you organize tabs into workspaces. We believe in radical transparency: this extension collects zero data about you.

Data Collection

We do not collect, transmit, or store any personal information. Specifically:

  • No analytics or telemetry of any kind
  • No tracking pixels, cookies, or fingerprinting
  • No user accounts or authentication
  • No network requests to external servers
  • No browsing history collection
  • No advertisements

Data Storage

All data created by this extension is stored entirely on your device using Chrome's built-in storage APIs:

  • chrome.storage.local — Workspaces (name, icon, saved tab URLs/titles) and cleaned tab history. This data never leaves your device.
  • chrome.storage.sync — UI preferences only (theme, font size, language, cleanup settings). This is synced across your devices through your Google account by Chrome itself. We have no access to this sync process.

You can export all workspace data as a JSON file and delete it at any time through the extension's settings.

Permissions

This extension requests the following Chrome permissions, each for a specific functional purpose:

  • sidePanel — To render the extension's UI in Chrome's side panel
  • tabs — To list, create, close, and organize browser tabs
  • tabGroups — To create and manage Chrome's native tab groups
  • storage — To save workspaces and user preferences locally
  • alarms — To run periodic auto-cleanup checks in the background

No permission is used for any purpose other than the extension's core tab management functionality. No data accessed through these permissions is ever transmitted externally.

Third-Party Services

This extension uses no third-party services, libraries, SDKs, or APIs. All code runs locally in your browser.

Import Feature

The import feature reads files you manually select from your device (OneTab .txt exports, Session Buddy .json exports, or our own backup format). These files are processed entirely in your browser and are never uploaded anywhere.

Children's Privacy

This extension does not knowingly collect any information from children under the age of 13.

Changes to This Policy

If we ever update this privacy policy, the changes will be posted on this page with an updated revision date. Given the nature of this extension (zero data collection), we do not anticipate significant changes.

Contact

If you have questions about this privacy policy, please open an issue on our GitHub repository.
